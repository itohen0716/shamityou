# 絲庵 ─ Shamisen ─ Ver.4.0.1

GitHub Pagesへ、そのままアップロードできる静的Webアプリです。

## 公開方法

1. ZIPを展開します。
2. 中のファイルとフォルダをGitHubリポジトリの最上位へ上書きします。
3. GitHub Pagesを `main` / `(root)` に設定します。
4. 公開URLを開き、調弦またはチューナー利用時にマイクを許可します。
