# 絲庵 ─ Shamisen ─ Ver.4.1

三味線の調弦・チューナー・耳トレーニングをまとめたGitHub Pages対応PWAです。

## 周波数マスター

- `tuning-master.xlsx` を唯一の編集用マスターデータとします。
- WebアプリはExcelから生成した `tuning-master.json` を直接読み込みます。
- 周波数を埋め込んだJavaScriptやCSVは管理しません。

## Ver.4.1

- 調弦中の目標Hz・測定Hz・判定を保持表示
- 表示判定と自動進行判定を共通閾値へ統一
- 「調子を当てる」の問題音ループ再生と調子ボタン即時回答
- 「音を合わせる」の2音ループ・音程変更時リアルタイム再生
- 時間切れ後のHzヒント付き再チャレンジ（正解数への加算なし）
- PWAキャッシュをVer.4.1へ更新
