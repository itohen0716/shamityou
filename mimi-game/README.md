# 耳を育てる Ver.1.0

GitHub 上の既存 `mimi-game` フォルダを、このフォルダの内容で上書きするための完成版です。

## 収録ゲーム

### ① 調子を当てる
- 簡単：6本固定、問題音を繰り返し再生
- 普通：1〜8本からランダム、問題音を繰り返し再生
- 難しい：1〜12本からランダム、自分で再生
- 本数はクイズにせず画面表示
- 本調子 / 二上り / 三下りを回答

### ② 何本か当てる
- 簡単：連続した3音
- 普通：連続した5音
- 難しい：完全ランダム3音
- 達人：完全ランダム4音（難しいクリアで解放）
- 超達人：完全ランダム5音（達人クリアで解放）
- A/B/C/D/E のラベルを表示
- 再生中のラベルのみ色が変わる
- 回答後、各ラベルが実際の本数表示へ変わる

### ③ 音を合わせる
- 簡単：30秒
- 普通：20秒
- 難しい：15秒
- 基準音とずらした音を聴き比べ、上げ下げして合わせる
- ±5 cent以内で正解

## 共通仕様

- 1ゲーム10問
- 8問以上正解でクリア
- 正解数 / 連続正解 / 最高連続正解
- シャミの表情切替
- 累計正解数で耳レベル
  - Lv.1 初心者
  - Lv.2 見習い
  - Lv.3 中級
  - Lv.4 名人
  - Lv.5 達人
- 進捗は localStorage に保存
- 三味線耳認定条件
  1. 調子を当てる「難しい」クリア
  2. 何本か当てる「超達人」クリア
  3. 音を合わせる「難しい」クリア
- 条件達成で「三味線耳認定！」と認定証を表示

## 音源

新しい音源は追加していません。
既存アプリ直下の次の共通ファイルを利用します。

- `tuning-data.js`
- `sound-segments.js`
- `audio-engine.js`
- `sounds/teacher-1to12-octave.wav`

そのため、この `mimi-game` フォルダだけを上書きしてください。

## 注意

PWAのService Workerが古いファイルを保持している場合、GitHub Pages更新後に古い画面が見えることがあります。
その場合はブラウザの再読み込み、またはサイトデータの更新が必要になることがあります。
